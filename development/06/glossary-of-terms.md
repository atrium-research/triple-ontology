# Glossary of Terms (Iteration 6)

| Term                        | Definition                                                                                                                                                                                                                          |
|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `triple:Document`           | A class representing any type of scholarly resource available on the GoTriple platform, including articles, conference papers, research datasets, and project descriptions. Subclass of both `schema:CreativeWork` and `foaf:Document`. |
| `triple:Profile`            | A class representing a profile in the GoTriple system. Every profile is either a person or an organization (`triple:Profile` is a subclass of the union of `foaf:Person` and `foaf:Organization`). It may or may not be associated with a user account.                |
| `foaf:Person`               | A class representing a person, from FOAF. One of the two classes whose union subsumes `triple:Profile`.                                                                                                                                                                        |
| `foaf:Organization`         | A class representing an organization, from FOAF. One of the two classes whose union subsumes `triple:Profile`.                                                                                                                                                                 |
| `foaf:OnlineAccount`        | A class representing a user account on the GoTriple platform. Can be associated with author profiles.                                                                                                                               |
| `schema:author`             | An object property linking a document to its author profiles (`triple:Profile` instances).                                                                                                                                          |
| `foaf:account`              | An object property linking a profile to a user account. If a profile has an account, it is associated with a user; otherwise, it is not associated. Maximum cardinality: 1.                                                         |
| `schema:name`               | A data property specifying the full name of a profile as extracted from publications. Range: `xsd:string`. Required exactly once for each profile.                                                                                  |
| `datacite:Identifier`       | A class representing an identifier for an entity (profile or account).                                                                                                                                                              |
| `datacite:IdentifierScheme` | A class representing the scheme or system used for identifiers.                                                                                                                                                                     |
| `datacite:hasIdentifier`    | An object property linking an entity (profile or account) to its identifier. Required exactly once for each profile.                                                                                                                |
| `datacite:usesIdentifierScheme` | An object property linking an identifier to the scheme it uses.                                                                                                                                                                 |
| `datacite:ark` | Identifier scheme of the persistent identifier minted by GoTriple: an ARK. |
| `triple:internal_id_schema` | Identifier scheme of the internal identifier assigned by the GoTriple platform. |
| `triple:original_id_schema` | Identifier scheme of the identifier a resource carried in the system it was harvested from. |
