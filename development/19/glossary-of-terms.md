# Glossary of Terms (Iteration 19)

| Term                                        | Definition                                                                                                                                                              |
|---------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `triple:Profile`                            | A profile representing either a person or an organization in the GoTriple system, associated or not with a user account. Enriched in this iteration with personal names, self-description, pronouns, photo, personal web page, disciplines of interest, thesaurus keywords, known languages, affiliation, registration/collaboration flags, person PIDs and last update date. |
| `triple:pronouns`                           | Datatype property recording the personal pronouns chosen by the user for their profile (e.g. "she/her").                                                                |
| `triple:registeredUser`                     | Datatype property (boolean) stating whether the profile belongs to a registered GoTriple user or was automatically created for a harvested author.                      |
| `triple:openToCollaboration`                | Datatype property (boolean) stating whether the registered user declared to be open to collaboration with other GoTriple users.                                         |
| `triple:ID`                                 | Internal identifier used within the GoTriple platform for resource management. On profiles it carries the Elasticsearch id.                                             |
| `triple:PID`                                | Persistent identifier generated and exposed externally by the GoTriple platform. On profiles it carries the `pid` field, distinct from the OPERAS/GoTriple id.          |
| `triple:Discipline`                         | A discipline of the GoTriple classification, subclass of `skos:Concept`.                                                                                                |
| `triple:Document`                           | A document in the GoTriple platform.                                                                                                                                    |
| `triple:idref_schema`                       | Identifier scheme for IdRef, the French authority file for higher education and research maintained by ABES (not present in the DataCite ontology).                     |
| `triple:gotriple_id_schema`                 | Identifier scheme for the OPERAS/GoTriple identifier assigned to a profile (the `goTripleId` field).                                                                    |
| `foaf:givenName`                            | The given name (first name) of a person, from the FOAF vocabulary.                                                                                                      |
| `foaf:familyName`                           | The family name (last name) of a person, from the FOAF vocabulary.                                                                                                      |
| `foaf:topic_interest`                       | A thing of interest to an agent, from the FOAF vocabulary. Used to link a profile to the disciplines the user chose or that were automatically detected.               |
| `foaf:Person`                               | A person, from the FOAF vocabulary.                                                                                                                                     |
| `foaf:Organization`                         | An organization, from the FOAF vocabulary.                                                                                                                              |
| `schema:name`                               | The name of an entity, from Schema.org. On profiles it carries the full name as received in the publication metadata.                                                  |
| `schema:description`                        | A description of an entity, from Schema.org. On profiles it carries the user's self-description.                                                                        |
| `schema:knowsAbout`                         | A topic known about by the agent, from Schema.org (declared for Person and Organization). Used with `schema:DefinedTerm` values from the TRIPLE thesaurus.              |
| `schema:knowsLanguage`                      | A language known by the agent, from Schema.org.                                                                                                                         |
| `schema:affiliation`                        | An organization the agent is affiliated with, from Schema.org.                                                                                                          |
| `schema:image`                              | An image of the entity, from Schema.org. On profiles it carries the URL of the personal picture chosen by the user.                                                    |
| `schema:url`                                | The URL of the entity, from Schema.org. On profiles it carries personal web pages.                                                                                     |
| `schema:dateModified`                       | The date on which the entity was most recently modified, from Schema.org. On profiles it records the last GoTriple update.                                             |
| `schema:author`                             | The author of a content, from Schema.org. The documents a profile is author of are retrieved as the inverse of this property.                                          |
| `schema:headline`                           | The headline (title) of a content, from Schema.org.                                                                                                                     |
| `schema:DefinedTerm`                        | A word, name, acronym or phrase defined in a controlled vocabulary, from Schema.org. Used for structured thesaurus keywords.                                            |
| `schema:Language`                           | A natural language, from Schema.org.                                                                                                                                    |
| `schema:URL`                                | A URL data type, from Schema.org.                                                                                                                                       |
| `datacite:hasIdentifier`                    | Links an entity to one of its identifiers, from the DataCite ontology.                                                                                                  |
| `datacite:usesIdentifierScheme`             | Links an identifier to the scheme it uses, from the DataCite ontology.                                                                                                  |
| `datacite:Identifier`                       | An identifier of an entity, from the DataCite ontology.                                                                                                                 |
| `datacite:IdentifierScheme`                 | The scheme an identifier belongs to, from the DataCite ontology.                                                                                                        |
| `datacite:orcid`                            | Identifier scheme for the Open Researcher and Contributor ID (ORCID), from the DataCite ontology.                                                                       |
| `datacite:isni`                             | Identifier scheme for the International Standard Name Identifier (ISNI), from the DataCite ontology.                                                                    |
| `datacite:researcherid`                     | Identifier scheme for ResearcherID, from the DataCite ontology.                                                                                                         |
| `datacite:local-resource-identifier-scheme` | Identifier scheme for local resource identifiers, from the DataCite ontology. Used for the internal Elasticsearch id of the profile.                                    |
| `litre:hasLiteralValue`                     | The literal value of an identifier, from the SPAR literal ontology.                                                                                                     |
