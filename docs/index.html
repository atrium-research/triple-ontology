The TRIPLE Ontology

Version 3.2.0 · the data model of the GoTriple discovery platform

The TRIPLE Ontology defines a comprehensive model for representing Social Sciences and Humanities (SSH) resources in the GoTriple discovery platform. The model and its six controlled vocabularies are published here as separate artefacts: each resolves at its IRI with content negotiation — HTML documentation for browsers, Turtle / RDF-XML / JSON-LD for semantic clients. Development happens on GitHub, where every release is archived.
