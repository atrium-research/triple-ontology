1. Introduction

Local proxy resources for the Dewey Decimal Classification classes that the Discipline vocabulary maps to. They are not TRIPLE disciplines: they are concepts of an external classification, minted locally because OCLC withdrew dewey.info and no dereferenceable DDC IRI exists.

Dewey Decimal Classification ni back to ToC

IRI: https://gotriple.eu/ontology/ddc

Local proxies for Dewey Decimal Classification classes, used as mapping targets by the Discipline vocabulary. OCLC withdrew dewey.info and no dereferenceable DDC IRI exists, so TRIPLE mints its own. Notations are those of the source vocabulary: some are truncated (78 for 780) and need review against the classification itself.

owl:Ontology c
skos:ConceptScheme c
has assertions
owl:versionInfo "3.0.0"
vann:preferredNamespacePrefix "ddc"
vann:preferredNamespaceUri "https://gotriple.eu/ontology/ddc/"
